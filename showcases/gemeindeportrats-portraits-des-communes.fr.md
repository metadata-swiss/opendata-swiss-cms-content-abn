Hier finden Sie statistische Porträts für alle Gemeinden der Schweiz. Suchen Sie die gewünschte Gemeinde direkt in der Datenbank Gemeindeporträts. Sie können auch statistische Kennzahlen von zwei Gebietseinheiten mittels eines Komparators direkt miteinander vergleichen. Vous trouverez ici les portraits statistiques de toutes les communes de Suisse. Sélectionnez une commune directement dans la banque de données Portraits des communes. Vous pouvez aussi comparer directement les données statistiques de deux territoires à l'aide d'un comparateur.
