Hier finden Sie statistische Porträts für alle Kantone der Schweiz. Wählen Sie einen Kanton auf der Karte oder in der linken Navigation. Sie können auch statistische Kennzahlen von zwei Gebietseinheiten mittels eines Komparators direkt miteinander vergleichen. Vous trouverez ici les portraits statistiques de tous les cantons suisses. Sélectionnez un canton sur la carte ou dans la navigation de gauche. Vous pouvez aussi comparer les données statistiques de deux territoires à l'aide d'un comparateur.
