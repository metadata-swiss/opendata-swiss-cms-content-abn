GeoML ist eine interaktive ML-basierte Web-App in Form einer Challenge zum Thema Strassengefährdung. Ihre eigene Einschätzung von Strassengefahren auf Basis von Luftbildern wird mit der eines ML-Modells verglichen. Mit GeoML können Sie Ihre Einschätzungsfähigkeiten auf spielerische Art und Weise testen. GeoML est une application web interactive basée sur le machine learning sous forme de défi sur le thème des dangers routiers. Votre propre évaluation des dangers routiers sur la base de photos aériennes est comparée à celle d'un modèle de machine learning. Avec GeoML, vous pouvez tester vos capacités d'évaluation de manière ludique.
